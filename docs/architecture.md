# Architecture de Nova

## Stack technique
- Frontend : HTML, CSS, JavaScript
- Backend : Node.js, Express
- Base de données : Supabase
- Stockage médias : Cloudflare R2
- Paiement : GeniusPay
- Déploiement : Vercel

## Structure
- `frontend/` : Interface utilisateur
- `backend/` : Serveur Node.js
- `database/` : Scripts SQL
- `docs/` : Documentation
